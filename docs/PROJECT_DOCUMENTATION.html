ACADEMIC PROJECT REPORT

DIABETES PREDICTION USING MACHINE LEARNING

Clinical Risk Stratification via 5-Fold Stratified Cross-Validation & Weighted Soft Voting Ensembling

1. Clinical Diagnostic Features

Attribute Type Unit Clinical Significance
Pregnancies Discrete Count Number of pregnancies; correlated with gestational diabetes history.
Glucose Continuous mg/dL 2-hour plasma glucose from Oral Glucose Tolerance Test (Primary biomarker).
BloodPressure Continuous mm Hg Diastolic blood pressure; metric for hypertension and vascular health.
SkinThickness Continuous mm Triceps skinfold thickness; estimator of subcutaneous body fat.
Insulin Continuous μU/mL 2-hour serum insulin; measures beta-cell function and insulin resistance.
BMI Continuous kg/m² Body Mass Index; key metric for obesity (BMI ≥ 30 indicates high risk).

Age Continuous Years Chronological age; type 2 diabetes prevalence rises significantly with age.
Outcome Binary {0, 1} Ground truth target: 0 (Non-Diabetic), 1 (Diabetic).

3. Mathematical Formulation

1. Biological Zero Handling & Median Imputation:

In living humans, measurements for Glucose, Blood Pressure, Skin Thickness, Insulin, and BMI cannot be zero. Zeroes indicate unrecorded observations and are imputed using median values to preserve feature distributions:

Imputed(x) = median(x) if x == 0 or null, else x

2. Interquartile Range (IQR) Outlier Mitigation:

IQR = Q3 - Q1 Bounds = [Q1 - 1.5 * IQR, Q3 + 1.5 * IQR]

3. Feature Normalization (Z-Score Standardization):

Z = (x - μ) / σ (Computed strictly on training fold to prevent data leakage)

4. Weighted Soft Voting Ensemble (Proposed Model):

P_en(i) = Σ [ W_j * P_ij ] / Σ Σ [ W_j * P_ij ] Where W_j = Cross-Validated ROC-AUC score of Classifier j

5. System Architecture & Execution

The system is packaged in standard modular form with full CLI and Web GUI capabilities:

  • Interactive Web App: Launch via run_app.bat or py -3.10 -m streamlit run app.py (Accessible at http://localhost:8501).
  • Full Pipeline Training & Evaluation: Run via run_pipeline.bat or py -3.10 main.py --mode all.
  • Patient CLI Prediction: py -3.10 predict.py --glucose 150 --bmi 32.5 --age 45.
  • Automated Unit Tests: py -3.10 -m unittest discover -s tests -p "test_*.py" -v.
